
## Новый раннер

Структура сохраняется. Подготовленный набор для раннера лежит в
`Queries/<движок>/<датасет>/<набор>/`. Например,
`Queries/rpqmatrixGB/rpq_250k/basic4/` содержит `manifest.json`
с ID и эталонными результатами, а также `matrix.tsv`.
Новый набор размещается рядом со старыми файлами. Для конвертации используйте
[инструкцию](../Scripts/converters/README.md).
