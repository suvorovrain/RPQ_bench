# Скрипты RPQBench

- [converters](converters/README.md) — источник графа, общие форматы входов и отдельные пакеты запросов для движков.
- [runners](runners/README.md) — запуск одного или нескольких движков и конфигурация эксперимента.
- [analyse](analyse/README.md) — таблицы и гистограммы по сохранённым выборкам.

Исторические файлы находятся локально в `Scripts/archive/`, `Scripts/converters/archive/`,
`Scripts/runners/archive/` и `Scripts/analyse/archive/benchmarks/`.
В последнем каталоге сохранён весь бывший `Scripts/benchmarks`, включая
`benchmark_results/wikidata*`. Старые прогоны находятся в `Results/archive/`.
Архивы исключены из Git. Старые скрипты могут ссылаться на прежние пути.
