# Анализ прогона

```bash
python -m pip install -r Scripts/analyse/requirements.txt
python -m Scripts.analyse.report Results/rpq_250k/<run>
```

Пишет таблицу статистик `summary.csv`, таблицу сырых измерений
`samples.csv`, машинную сводку `summary.json` и диаграммы `timings-*.png` по запросам
в подпапку `analysis`. `--tables-only` отключает графики.
На диаграммах движки расположены по X, время в миллисекундах — по Y
на логарифмической шкале. Столбцы показывают медианы, точки — отдельные замеры.
В таблицах есть и дополнительные фазы, например парсинг и оптимизация
MillenniumDB. Поле `chart` отмечает основную серию каждого движка.
Нулевые показания отображаются счётчиком рядом с медианой и сохраняются в CSV.
Границы таймеров описаны в [раннерах](../runners/README.md#что-измеряет-каждый-раннер).
Неуспешные движки включаются в список ошибок, а независимая серия
подготовленного Pathrex сохраняется с отдельной меткой в таблицах.

Старые анализаторы и результаты Wikidata физически сохранены в
`archive/benchmarks/benchmark_results`. Новый анализатор читает новый
формат прогона.
